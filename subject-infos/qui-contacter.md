# Qui contacter

> Source : https://docmost.alsacedigitale.org/share/7znmwljzor/p/qui-contacter-eckPmpH0hb

## Pendant l'événement

- **Un problème matériel** (un bras qui ne répond plus, un câble, un driver) : le salon Discord **support-technique**, ou quelqu'un de l'équipe coaching dans la salle.
- **Une question d'organisation** (repas, accès, horaires) : l'accueil, ou le salon **blabla**.
- **Les annonces officielles** arrivent dans le salon **annonces**. C'est le seul fil qui fait foi.

## Avant l'événement

Pour toute question sur ton inscription, ton équipe ou tes contraintes alimentaires, passe par l'organisation d'Alsace Digitale.
